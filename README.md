# Minty 🌱

> **Earn scrolling time by doing something useful first.**

Think of it like a bank account for screen time: tasks are your job, minty minutes are your salary, and reels or social media are your shopping. You can only spend what you've earned.

## 💡 How It Works
1. **Add a task:** Set a task (e.g., "Study DSA for 1 hour") and assign how many minutes it's worth.
2. **Complete it:** Tap "Complete" and those minutes are deposited into your balance.
3. **Check balance:** Home screen displays your running balance.
4. **Spend minutes:** Tap "Start scrolling" to begin the countdown while using social media or reels.
5. **Warning:** A notification warns you when your time is almost up.
6. **Review:** History screen logs all completed tasks.

## 🛠 Tech Stack
- **Language:** Java
- **Database:** SQLite (local offline storage)
- **Minimum SDK:** 24 (Android 7.0)
- **Target SDK:** 33 (Android 13)
- **UI:** Android Material Design Components
